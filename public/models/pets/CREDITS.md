## Additional 2D companions

`personal-cat.webp` and `personal-dog.webp` were generated with the built-in imagegen tool from the owner's supplied reference photos. `rabbit.webp` and `hamster.webp` were generated with the same tool. These transparent character illustrations use lightweight animation; they are not rigged 3D models.

Prompts: preserve the reference cat's round face, cream/silver plush fur, pink nose and dark eyes; preserve the reference dog's fluffy ivory coat, upright ears, dark eyes, black nose and curled plume tail. Full-body three-quarter view, natural anatomy, warm studio lighting, transparent background, no accessories or text. Rabbit: lifelike cream lop-eared rabbit, full body, soft drooping ears and plush fur. Hamster: lifelike golden Syrian hamster, cream belly, rounded ears and tiny pink paws. Both use the same transparent full-body studio presentation.
